# KUROX

### Studio Operations • CRM • Production • Marketing • SEO

**Kurox** is a CRM-driven studio management platform designed to manage the complete lifecycle of creative and production projects in one place.

From **customers and projects to shoots, assets, marketing, SEO, quotations, invoices, and analytics**, Kurox connects studio operations into a unified ecosystem.

## ✨ Features

* 📇 CRM & Customer Management
* 🎬 Project & Shoot Management
* ✅ Task & Workflow Automation
* 📸 Asset & Shot Management
* 📅 Calendar & Scheduling
* 📢 Marketing & Campaign Analytics
* 🔍 SEO Management & Reporting
* 💰 Quotes, Invoices & Payments
* 👥 Team & Role Management
* 📊 Business Analytics
* 🔔 Notifications & Activity Tracking
* 🔐 Role-Based Permissions
* 📱 Web & Mobile Support

## 🛠️ Tech Stack

* **Frontend:** React + TypeScript
* **Mobile:** React Native + Expo
* **Backend:** FastAPI + Python
* **Database:** PostgreSQL
* **Caching:** Redis
* **Storage:** S3-compatible storage
* **API:** REST + OpenAPI
